Reads of another slice's table without the owner's read function: `applications.ts` → `Quote` (finding 2, fixed) and `invoices.ts` → `Contract` (finding 3, open; the owner does not exist yet). `actor.ts` → `Customer` is the base slice reading its own table.

Handlers registered through `src/server/event-handlers.ts`: invoicing (`CONTRACT_SIGNED`) and the passport (`CONTRACT_SIGNED`, `UNIT_RETURNED`, `CONTRACT_BOUGHT_OUT`, `UNIT_PASSED_ON`). The catalogue's handlers that set `leased` / `sold` (D22) are missing (finding 4).
- Feature pages against `docs/features/README.md`: the sections in order, the worked example on the card numbers, the D numbers, every file path and link resolves on the branch (script over the five pages and the README: none missing).
